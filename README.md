# 🚀 FlowDesk

FlowDesk is a modern, responsive landing page for an AI workflow automation platform.

The project was built to practice writing clean, semantic HTML and scalable CSS while following modern frontend development practices. The focus was on creating a professional user interface with reusable components, responsive layouts, and smooth user interactions without relying on CSS frameworks or JavaScript libraries.

## ✨ Features

- Responsive Design (Mobile First)
- Clean Semantic HTML5
- Modern CSS Architecture
- CSS Variables
- Flexbox & CSS Grid Layouts
- Smooth Hover Animations
- Accessible Navigation
- Optimized Images (WebP)
- SVG Icons
- Reusable Components
- Clean File Structure
